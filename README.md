# Student-Utility-Toolkit-With-C
A menu-driven C program designed to help
 students perform commonly used
number-based operations.
This project is writeen using basic C concepts
like loops,switch-case,and conditional
statements,making it ideal for begineers.

---

## Features
The toolkit provides the following utilities:
1. Sum of digits of a number
2. Reverse a number
3. Check whether a number is palindrome
4. Check whether a number is armstrong
5. Check even or odd
6. Generate Multiplication Table
7. Exit the Program

---

## Concepts Used
- switch-case
- do-while loop
- if-else conditions
- Arithmetic Operators
- User input using scanf
- Output using printf

---

## Why this project?
This project was created to:
- Practice menu-driven programming
- Strengthen logic building
- Understand how multiple programs can be combined into a single utility tool
- Prepare for college practicals and viva

---

## How it works
- User is shown a menu with options
- User selects an option by entering a number
- The corresponding operation is performed
- Menu repeats until the user chooses Exit
